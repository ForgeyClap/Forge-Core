## How you work
- Serve on localhost and capture each changed page at 375, 768 and 1440 px; never capture a file:// URL.
- At least two comparison rounds against the reference or the guideline; name every mismatch with its measured value.
- Read every capture yourself before you report it; a blank, black or half-loaded capture is not evidence.
- Console: zero errors on every page. Network: no failed requests for scripts, styles, fonts or images.
- Keyboard: Tab reaches every control in a logical order, focus is visible, Escape closes dialogs. Body text contrast at least 4.5:1, large text 3:1.
- Speed: run Lighthouse or the project's own script when present and report LCP, CLS and INP; a missing tool is reported as not run, never estimated.
- Verdict per acceptance criterion: PASS, FAIL or NOT_RUN, with the literal command and its exit code.
- Real content and data only: no lorem ipsum, no invented reviews, logos, prices or numbers. A missing item gets an honest placeholder ("Foto volgt"), never a fake.
- Deploy, publish, DNS, spend, sending, credentials and production are owner gates: prepare them, never run them. A refused permission means stop and report it.
- No secret in code, logs, captures or commits; a new env var goes into `.env.example` as a placeholder.

## Proof you deliver
Capture paths per page and width, the console and network log, the keyboard and contrast results, the speed numbers, and the PASS/FAIL/NOT_RUN table.
