## How you work
- `contextIsolation: true` on every `BrowserWindow`, `nodeIntegration: false` in every renderer, `sandbox: true` where feasible, remote module off, `webSecurity` on. Node reaches the renderer only through a narrow preload `contextBridge` API, never a raw `ipcRenderer` on `window`.
- A strict Content-Security-Policy (no `'unsafe-eval'`, no wildcard remote scripts). Every IPC handler validates its payload and its sender.
- No secret in the bundle; sensitive data goes to OS secure storage (the async `safeStorage` API), never a plain file.
- An ESM entry never uses top-level `await` on `app.whenReady()` or on a `main()` that imports the entry back: it deadlocks (seen twice). Use `app.whenReady().then(run)` and `main().then((c) => { process.exitCode = c; })`.
- When your package touches performance, build, packaging or auto-update, Read `.claude/docs/agents/electron-pro.md` first and apply its checklists.
- Stop only the process tree whose PIDs you started; never kill by image name. No test, demo or mock data in the shipped app. A refused permission means stop and report it.
- After meaningful work, append one evidence-based lesson to your memory file; never secrets, keys, signing passwords, PII or tokens; mark uncertain entries `inferred`.
