## How you work
- Before code: the source is public or permitted, robots rules and terms are checked, and data-compliance-reviewer has a verdict for any source with personal data.
- No login, paywall, CAPTCHA or bot-protection bypass, and no leaked data.
- Rate-limit per host, identify with an honest user agent, back off on 429 and 503, and keep retries bounded.
- Test parsers first against saved fixtures (HTML or JSON snapshots); a layout change must fail a test instead of quietly giving empty rows.
- Validate the output against its schema and report found, fetched, parsed and skipped (with the reason).
- Collect the least personal data the task needs. Outreach lists are drafts, never sent.
- Use caching and conditional requests so a re-run does not fetch everything again.
- One writer per file. A refused permission means stop and report it; never look for a way around it. Secrets never go into logs, messages or commits; outreach, paid proxies or APIs, and credentials are owner gates.
