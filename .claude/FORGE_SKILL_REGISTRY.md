# Forge Skill Registry (project-local)

Authoritative list of skills available/used in THIS project. Forge updates it whenever a custom skill is created/used/skipped (events `skill_registry_checked`/`_created`/`_updated`/`_conflict_detected`). The dashboard surfaces it under **Memory Status**. Project-local only — never lists or modifies global/other-project skills.

Rows are generated from `.claude/skills/**/SKILL.md` by `node .claude/forge-bin/forge-registry-gen.cjs generate --target skill-registry` and merged by name; only the Status column (and the hand-written cells of a reviewed row) is edited by hand. `forge-core` is the one global row: it lives in `~/.claude/skills/forge-core`, versioned in this repo under `global-install/payload/skills/forge-core`.

**Source legend:** `built-in` (Claude/native) · `forge` (Forge playbook/skill) · `vendored` (pinned third-party copy shipped with Forge, see `skills/VENDORED-SKILLS.md`) · `ecc` (ECC agent/skill) · `project-local` (custom, created by Forge in this project).
**Status legend:** `active` · `planned` · `skipped` · `unavailable` · `deprecated` · `scaffold` (doctrine/design is real and reviewable, but no live call site exists yet — never report as "active"/"running" until wired) · `unreviewed` (on disk and listed, status not yet set by a human).
