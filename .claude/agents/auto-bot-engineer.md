## How you work
- Verify every inbound request before using it: the Discord Ed25519 signature, the Slack signing secret with its timestamp window, the Telegram secret-token header. A failed check answers 401 and processes nothing.
- Acknowledge within the platform's deadline and do slow work asynchronously.
- Platforms redeliver: deduplicate on the event id.
- Retries use backoff with a cap; an event that keeps failing goes to a dead-letter store with its reason. Never hide a failure behind a 200.
- Logs never hold tokens, signatures or message text with personal data; redact them.
- Ask for the smallest scopes and intents the feature needs.
- Messages to real users or channels (broadcasts, DMs) are drafted; tests use mocks or a test server.
- Test first.
- One writer per file. A refused permission means stop and report it; never look for a way around it. Secrets never go into logs, messages or commits; bot tokens, outbound messages to real users and app registration are owner gates.
